# 编写值班日报页面

- 路由：`/phase-one/duty-report/new`
- 入口：综合业务系统顶部「值班值守」或页签「编写日报」；顶部「信息接报」可返回原来的事件列表。
- 参考：2026-10-21 Chrome 中打开的综合业务管理系统「值班日报 → 编写日报 → 新增日报」。
- 主体：左侧值班信息、人员标签、附件区、人员在岗情况双层表头、9 家单位数据和合计行；右侧静态文档工具栏、红色日报抬头、正文和状态栏。
- 复用现有深色侧栏、顶部模块导航及文档预览组件，使用独立的日报样式。
- 表单、上传、保存、提交和文档格式按钮仅作样式展示，不调用业务接口。左右区域均可独立滚动；文档保持纸张宽度，可横向滚动查看。
- 用户头像、品牌和图标沿用项目既有模拟资源。
- 顶部「AI 编写日报」打开紧凑浮窗，可拖动标题栏移动，位置保持在视口内；支持「应急救援情况」「舆情上访情况」两个选填字段，内容纳入草稿对应章节。参考文档不限数量，仅支持 Word、PDF、TXT，单个不超过 10 MB。
- 点击「生成文稿」先逐项模拟人员数据、分类合计和选填信息校验，再在右侧编辑器逐步写入正文，浮窗与编辑器同步显示进度。生成期间锁定输入，关闭浮窗或按 Esc 会取消并恢复生成前正文；完成后可重新生成。浮窗自动移至左侧以展示编辑器。当前为本地演示，未调用模型，附件不参与生成。
- 校验过程显示在写作浮窗内部的独立弹窗中，完成后自动收起并生成文稿；支持取消校验。「应急救援情况」「舆情上访情况」为空或仅含空白时，对应章节正文写「无」。
