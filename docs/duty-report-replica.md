# 编写值班日报页面

- 路由：`/phase-one/duty-report/new`
- 入口：综合业务系统顶部「值班值守」或页签「编写日报」；顶部「信息接报」可返回原来的事件列表。
- 参考：2026-10-21 Chrome 中打开的综合业务管理系统「值班日报 → 编写日报 → 新增日报」。
- 主体：左侧值班信息、人员标签、附件区、人员在岗情况双层表头、9 家单位数据和合计行；右侧静态文档工具栏、红色日报抬头、正文和状态栏。
- 复用现有深色侧栏、顶部模块导航及文档预览组件，使用独立的日报样式。
- 表单、上传、保存、提交和文档格式按钮仅作样式展示，不调用业务接口。左右区域均可独立滚动；文档保持纸张宽度，可横向滚动查看。
- 用户头像、品牌和图标沿用项目既有模拟资源。
